# 双 Project 窗口

这个工具打开的是 Unity 原生 `ProjectBrowser`，不是简化版资源浏览器。因此原生搜索、拖拽、重命名、右键菜单、缩略图和项目已有的文件夹历史工具都会继续工作。

## 使用

1. 在现有 Project 窗口进入要固定的 `resource` 文件夹。
2. 选择 `UITools > Project 双窗口 > 打开锁定资源窗口`。
3. 新窗口会停在当前文件夹并自动锁定，标题显示为 `Project · 资源`。
4. 把新窗口停靠到合适位置；原 Project 窗口继续浏览或打开 Prefab。

也可以在 Project 窗口右键一个文件夹或资源，选择 `在锁定资源窗口中打开`。如果右键的是资源，工具会固定它所在的文件夹。

要让资源窗口重新跟随选择，点击它右上角的 Unity 原生锁头即可解锁。

## 兼容性

- 当前目标版本：Unity `2021.3.8f1`。
- Unity 没有公开 `ProjectBrowser` API，因此工具通过反射调用原生窗口。
- 如果未来 Unity 修改了内部接口，工具会保留现有 Project 窗口并给出手动操作提示，不会替换或关闭原窗口。
