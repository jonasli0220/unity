# Project 文件夹历史导航

为 Unity 原生 Project 窗口增加类似文件资源管理器的文件夹“后退 / 前进”能力。

## 使用

- 在 Project 窗口中依次打开不同文件夹，顶部工具栏会自动记录访问历史。
- 点击 `←` 返回上一个文件夹，点击 `→` 回到下一条历史。
- 快捷键：
  - 后退：`Alt + ←`
  - 前进：`Alt + →`
- 鼠标悬停在按钮上会显示即将前往的文件夹路径。

交互规则与文件资源管理器一致：后退后如果手动打开了另一个文件夹，旧的“前进”分支会被清除；历史中的文件夹若已删除，会在导航时自动跳过。

## 行为边界

- 每个 Project 窗口独立保存历史。
- 历史只在当前 Unity Editor 会话中保留，并能跨脚本编译 / Domain Reload 恢复；不会写入项目资源或团队设置。
- 单个窗口最多保留 64 条文件夹历史。
- 窗口过窄时，顶部按钮会隐藏以免覆盖 Unity 原生搜索和筛选控件，快捷键仍然可用。
- 工具扩展原生 `ProjectBrowser`，不会替换 Project 窗口，也不会改变搜索、选择、拖拽、重命名和右键菜单逻辑。

## 兼容性

当前实现针对项目使用的 Unity `2021.3.8f1`。它通过反射调用 Unity 的内部 `ProjectBrowser` 导航接口；如果未来 Unity 版本修改了接口，工具会安全停用并只输出一次可操作的警告，原生 Project 窗口仍可正常使用。
