# Generated Talent Tree Output Rules

- Keep one `<definition-name>.prefab`, `<definition-name>.json`, and `<definition-name>_Sprites/` generated image folder per tree in this directory, with Unity `.meta` files alongside imported assets. The image folder contains only deterministic `Inactive_<x>_<y>.png` tiles and spatially bucketed `ActiveAtlas_<x>_<y>_<page>.png` sheets.
- Both files are generated by merging the matching logic definition under `Editor/TalentTree/Definitions/` and UI layout under `Editor/TalentTree/Layouts/`. Do not hand-edit them; regenerate after either source changes.
- Patch-delivered prefabs must not introduce MonoBehaviour script types absent from the installed player. The export uses only Unity built-in UGUI components; the matching JSON owns source GUID, node IDs, prerequisites, edge IDs, exact positions/sizes, inactive tile paths, and active sprite keys. Game code creates visible `Node <id>` and `Edge <from> to <to>` views from JSON as needed.
- `Content/Nodes` is an empty RectTransform layer. Game code attaches visible node prefabs to this layer and sets positions and display sizes from JSON. Icons and node appearance configured in the editor are preview-only in the generated prefab; JSON retains node metadata and exact coordinates. Scale a mounted node prefab uniformly to its exported `size` instead of changing the shared source prefab's dimensions.
- The export computes a padded rectangular content size from node discs and Bezier curves, symmetric around the authored origin `(0,0)`. Prefab and JSON node positions must exactly match editor positions; `contentCenter` is zero. Do not include the six-sector editor guide or treat legacy `boardSize` as a fixed editor boundary.
- `Content/InactiveTiles` holds transparent Sprite Images at exact tile coordinates; `Content/ActiveEdges` is an empty RectTransform layer. Program code creates an `Image` when an active edge is visible and sets its rect from the JSON `activePosition` and `activeSize`. Do not add `Mask` or `RectMask2D` to the exported prefab; its embedding parent provides clipping. Keep raycast disabled on tile Images. Each active sprite name and atlas path is in JSON.
- Exported PNGs are owned by the matching JSON `generatedAssets` manifest. Re-export overwrites changed PNGs at stable paths, preserving `.meta` GUIDs, and removes only obsolete paths named by a valid prior manifest after the new prefab/JSON pair succeeds. Never bulk-delete the image folder. Do not edit generated image assets by hand; adjust layout style and re-export.
- Before replacing an existing prefab, verify its source definition GUID matches. Never overwrite an unrelated prefab or JSON file.
- Remove obsolete output pairs explicitly when their source definition is retired; do not bulk-delete this directory.
